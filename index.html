★ Key Concepts (cheat sheet)

✍️ Exam-day technique

  • Part A (predict output): draw names → arrows → boxes. Copy Python's exact format: ['a', 'b'] with single quotes and a space after each comma.
  • Part B (explain): mechanism + concrete example + fix, in 2–4 sentences.
  • Part C (find & fix): three labelled answers: Output / Cause / Fix.
  • Part D (write code): use exactly the construct named (comprehension, reduce, map + filter). Give reduce an initial value when the items are tuples.
  • Budget about 0.6 min per point. Stuck for more than 3 min? Skip it and come back.
